# c183 HC scale specialization: tiny parity sanity

Root-only, opt-in GPU work. Preparation did not compile or run HIP. Exactly seven BF16 patterns (+0, -0, +1, minimum subnormal, +infinity, quiet NaN 0x7fc0, signaling NaN 0x7f81) at scales 4096 and 512. Each arm has n=1 and freshly allocated/reset 16-word stats with two exterior sentinels; three-word input and output allocations also have sentinels. Compares all input/output/stats words plus expected exterior guard values after each pair. Fail-fast, at most 28 launches; success requires 14 pairs and 28 launches. One block of 256 threads matches the converter's guarded lane structure. These tiny cases establish smoke parity only, not exhaustive semantics, performance, model correctness, or deployment readiness.

Baseline ELF copied unchanged from c183-hc-current-source-20261009/isa/gemm.gfx906.elf, bound to frozen c183 binary by baseline-binding.json. Candidate ELF copied unchanged from the root's already-compiled resource-inspected package. No kernel compile step exists here. sanity.cpp is host-only HIP module loading and calls; root compiles this host driver only, using HIP headers/library, and records its compiler command, compiler version, output hash and exit code before execution. Example within the approved ROCm build environment: hipcc -std=c++17 -O2 sanity.cpp -o hc_tiny_sanity. Do not pass or compile hc_fixed_scale.hip or baseline device source.

Runner: python3 run_sanity.py --driver /absolute/path/hc_tiny_sanity --driver-sha <root-verified-sha256> --output /absolute/fresh/output --leave-api-stopped [--execute]. Without --execute only hashes and arguments are validated. All paths refer to the target MI50 host. Transfer the complete package unchanged; build the host driver outside the package. Root owns host compilation, review, transfer and GPU launch.

Unchanged native_support.py supplies device identity, fixed high mode, 190 W caps, cooldown <=55 C, and thermal monitoring at min(existing conservative ceiling, critical minus 10 C). Unchanged qsa_probe_safety.py supplies owned-name cleanup. Runner uses the existing shared exclusive nonblocking lock /tmp/strata-direct-ff34-ce.lock. All containers must be off before/after, including API. One UUID-owned container only; no API/power settings writes, model mounts, networking, retries or timing. Both physical GPUs are checked; HIP/ROCR exposure and driver select GPU0 only. Driver process timeout is 60 seconds; cooldown uses unchanged 900-second bound. Raw HIP return codes, raw half bits, all stats/guards, exit code, thermal samples and hash provenance survive failure. Any HIP failure exits the process; container/process teardown owns outstanding allocations on that path.

CPU-only test command: python3 -m unittest -v test_sanity.py. Tests statically enforce scope, validate pinned data, and mock successful/failing driver processes to check evidence and cleanup without Docker/GPU calls. They do not establish real HIP ABI or GPU parity; root's host compile and reviewed sanity run remain required.
